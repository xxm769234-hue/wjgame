# Unity 新手引导接入与验收

## 依据与当前范围

依据用户提供的《weijun-game-project-接口文档》第 56 节（2026-11-16，V165/V166 与 Unity 展示协议 2）完善客户端。继续兼容旧玩家已绑定的协议 1，不把 `contractVersion`、`guideVersion` 和迁移编号混用。

主工程为 `D:/weijun-game-project-branches/master`。本次源码备份、参考文档和验证材料位于 `D:/书屿梦行_新手引导完善_2026-11-19`；该目录中的备份是修改文件级备份，不是完整项目备份。

初始男女角色选择依用户要求暂缓业务接入，仅预留“选择你的初始伙伴”界面及“稍后再选”关闭入口。不会调用未明确的选择接口、发放角色或伪造步骤完成。服务器若停在 `CHOOSE_STARTER`，主线仍保留在该步骤；只有服务器允许时，玩家才可主动跳过。稍后补齐接口后再接入选择和发放。

主线与 11 条功能教程独立缓存版本、步骤和请求，一次只展示一条，主线优先。功能教程是否可分配由服务器决定，跳过其中一条不会重置其他教程。页面导航只打开或定位 UI，不自动消费、建造、领取或提交编队。

## 页面与交互

- 继续绑定 HomeScene 中已有的 `PlayerOnboardingManager` 和 `PlayerOnboardingCanvas`；缺少场景 UI 时才建立备用界面。
- 文案按纯文本显示，长正文可滚动。欢迎、介绍及完成对话保留完整面板；操作步骤使用纸色紧凑提示框并避让目标。高亮改为细金色角线，位于提示面板下方，不拦截点击，也不扩大到无关的整屏父按钮。
- 目标未加载或动作/锚点不支持时，不自动 ACK；提示可暂时收起，释放输入限制。
- 自动导航每步骤限制次数；用户关闭子面板或切换角色后，不持续抢回页面。
- 召唤结果窗口优先于下一步导航，玩家确认结果后再打开培养、编队或其他场景。
- 战斗播放期间隐藏引导及输入限制，继续读取权威进度，战斗结束后恢复。
- 初始伙伴预留页可关闭；收起状态跨场景和返回前台保留，不会再次把玩家拉回主页。实际步骤变化、显式恢复或重新登录后可重新显示，关闭不会把该步骤当作已完成。

## 协议与恢复检查

1. 列表使用 `GET /api/onboarding/guides`；按教程读取 `current`，按 `guideCode` 隔离 ACK、跳过及版本。旧后端不支持列表时兼容原主线路由，同时兼容 V83 种子的确认、聚焦地块、放置与建造动作，以及旧地图入口、免费地块和农场锚点。
2. 服务器快照是唯一进度依据。WebSocket 只触发读取；登录、重连、返回前台、场景恢复和业务成功后重新查询，业务步骤另有低频查询兜底。
3. ACK 和跳过发送前持久化 UUID、路径及完整请求体；断网、超时、5xx 保留原请求。重试不会改版本或创建另一笔意图。
4. 旧写响应不回退较新页面；不同教程的版本不互相比较；切换账号中止旧协程，待处理请求保留在原玩家名下。
5. 429、5xx 按退避策略处理并读取 `Retry-After`；自动提交次数受限，之后保留手动重试入口。
6. 8001、8004 等不确定状态重新查询；8005 保留冲突请求、停止自动重发，并提供收起入口，不用新 UUID 绕过冲突。
7. 已完成、已跳过和暂停状态遵循服务器结果，不因重新登录自行重启。仅在 `allowSkip=true` 时允许提交跳过。
8. 不支持的展示协议或不足的客户端版本进入既有更新检查，停止引导自动操作；通用 403 回到 Launch 执行合规检查。
9. 地块与建筑操作使用服务端绑定的实例 ID，不以同配置的其他实例代替。原业务权限、费用和限制继续有效。
10. 单抽恢复保留原请求号；未确认召唤结果时不能换档位创建新请求。教程查询和 ACK 本身不赠送或扣除彩墨。

## 验证与后续联调

隔离 Unity 工程使用实际项目脚本和真实 HomeScene 面板；网络协议测试使用 localhost fixture，不写正式账号数据。协议验证通过 21 组场景、66 项检查，异常恢复通过 2 组、9 项，旧版兼容与展示恢复通过 3 组、24 项；真实页面通过 74 项检查，运行时错误 0，留存 9 张页面截图。完整结果及边界见输出目录的 `验收结果.md`，原始 JSON 报告位于 `验证/`，页面报告为 `验证/页面/onboarding-pages-validation.json`。

本次不部署后端、不修改数据库、不替正式账号开启教程或重置进度。正式新账号端到端验收仍需已发布开放的教程策略、可达业务配置及后续补齐的初始角色选择接口；经营地图和战斗流程还需在真实账号环境验证完整业务链。当前后端未分配教程时不显示引导是正常行为。

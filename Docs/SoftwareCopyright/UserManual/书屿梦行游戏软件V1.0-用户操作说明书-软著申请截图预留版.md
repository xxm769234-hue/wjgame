## 1. 文档说明

### 1.1 编写目的

本说明书用于介绍书屿梦行游戏软件 V1.0 的运行环境、界面组成、主要功能和操作方法，帮助用户完成软件启动、账号登录、角色培养、模拟经营、战斗冒险及其他游戏操作。本说明书同时作为书屿梦行游戏软件 V1.0 申请计算机软件著作权登记的文档材料。

### 1.2 适用范围

本说明书适用于书屿梦行游戏软件 V1.0。文中所述功能以该版本正式发布客户端的实际界面和可操作结果为准。

### 1.3 操作约定

- “点击”是指在移动设备上轻触对应按钮或界面元素。
- “返回”是指关闭当前功能页面并回到上一级页面。
- 界面中的角色、资源、商品、任务和奖励内容可能随正式配置变化，但操作方式保持一致。
- 软件需要连接网络完成登录、数据读取、资源同步及游戏操作。

## 2. 软件概述

### 2.1 软件简介

书屿梦行游戏软件是一款融合角色培养、模拟经营和战斗冒险玩法的网络游戏。软件以书页式首页作为主要功能导航，用户可在不同功能页面中管理角色和装备、查看仓库、完成任务、使用商城、参与角色召唤、维护好友关系，并进入模拟经营或战斗冒险模式。

### 2.2 主要功能

- 提供账号注册、账号登录、微信登录和隐私协议确认功能。
- 提供角色、装备、仓库和角色召唤功能。
- 提供任务、签到、商城、资源出售和奖励领取功能。
- 提供好友申请、好友互动、邮件、公告和通知功能。
- 提供地块购买、地块净化、建筑建造、升级、移动、拆除和生产收取功能。
- 提供队伍编成、关卡战斗、暂停恢复、战斗结算和挂机奖励功能。
- 提供个人资料、昵称、头像、声音、画质、帧率和账号管理功能。

### 2.3 软件操作流程

用户启动软件后，在开始页面点击“开始游戏”，完成隐私协议确认并选择登录方式。登录成功后进入游戏首页，再通过首页入口进入角色、装备、仓库、商城、好友、任务、模拟经营或战斗冒险等功能。完成操作后，可通过关闭或返回按钮回到首页。

## 3. 运行环境与启动

### 3.1 运行环境

书屿梦行游戏软件 V1.0 适用于能够正常运行微信客户端及微信小游戏的移动终端。推荐运行环境如下：

| 项目 | 运行要求 |
| --- | --- |
| 终端类型 | 智能手机或其他受支持的移动终端 |
| 操作系统 | Android 或 iOS |

| 网络环境 | 可正常访问互联网的移动网络或无线网络 |

3. 正常加载后，页面显示游戏标志、“开始游戏”按钮、隐私同意选项和健康游戏提示。
4. 点击“开始游戏”进入登录操作。
5. 如页面提示版本更新或服务器维护，应按提示完成更新或稍后重新进入。

## 4. 用户登录与首次使用

### 4.1 打开登录窗口

用户点击开始页面中的“开始游戏”后，系统打开账号登录窗口。登录窗口包括账号、昵称、密码输入框，以及登录、注册并登录、微信登录、设置、邮件和关闭按钮。

### 4.2 查看并同意隐私协议

1. 点击开始页面中的“查看隐私协议”。
2. 在隐私协议页面中阅读协议正文。
3. 点击“关闭”返回开始页面。
4. 勾选“我已阅读并同意当前隐私协议”。
5. 完成勾选后再执行登录、注册或微信登录。

未勾选隐私同意选项时，系统会提示用户先阅读并同意当前隐私协议。

[[SCREENSHOT|图 2|登录窗口与隐私同意|02-login-dialog.png]]

[[SCREENSHOT|图 3|隐私协议页面|03-privacy-agreement.png]]

### 4.3 注册账号

1. 在账号输入框中填写拟注册的账号。
2. 在昵称输入框中填写游戏昵称。
3. 在密码输入框中填写登录密码。
4. 根据需要勾选记住登录信息。
5. 确认已勾选隐私同意选项。
6. 点击“注册并登录”。
7. 注册成功后，系统保存账号资料并进入游戏首页。

若账号、昵称或密码不符合要求，页面会显示相应提示，用户修改后可重新提交。

### 4.4 使用账号登录

1. 输入已注册的账号和密码。
2. 确认已勾选隐私同意选项。
3. 点击“登录”。
4. 登录成功后进入游戏首页。

### 4.5 使用微信登录

1. 确认已勾选隐私同意选项。
2. 点击“微信登录”。
3. 按微信页面提示完成授权。
4. 首次登录时，根据页面提示补充昵称等必要资料。
5. 授权及登录成功后进入游戏首页。

### 4.6 首次使用引导

新用户首次进入软件时，系统可显示功能引导。用户根据引导文字和高亮区域依次点击对应入口，了解首页、经营和其他基础功能。若当前引导步骤允许跳过，可点击页面中的跳过按钮结束引导。

## 5. 游戏首页

### 5.1 首页组成

登录成功后进入书页式游戏首页。页面主要包括以下区域：

- 头像、昵称、等级和经验信息区。
- 净化剂、体力、金币和钻石等资源信息区。
- 角色、装备、仓库、商城、好友、召唤和任务入口。
- 战斗模式和建造模式入口。
- 邮件、公告、设置、活动和签到等快捷入口。
- 页面状态和系统提示区域。

[[SCREENSHOT|图 4|游戏首页与功能入口|04-home-page.png]]

### 5.2 查看资源和等级

1. 在首页头像区域查看当前昵称、等级和经验进度。
2. 在顶部资源栏查看净化剂、体力、金币和钻石数量。
3. 完成任务、购买、领取或经营操作后，首页会显示同步后的资源数据。
4. 若数据未及时变化，可返回首页或重新进入相关页面刷新。

### 5.3 进入和退出功能页面

点击首页中的功能图标即可进入对应页面。完成操作后，点击页面右上角的关闭按钮或页面中的返回按钮，即可回到首页。部分页面提供分页、分类或上一页、下一页按钮，用户可按页面提示切换内容。

## 6. 角色管理

### 6.1 打开角色页面

1. 在首页点击“角色”。
2. 系统读取当前账号拥有的角色并显示角色列表。
3. 点击列表中的角色，右侧或详情区域显示角色信息。

### 6.2 查看角色信息

角色详情可显示角色名称、品质、获得状态、等级、战斗属性、生产加成、角色描述和获得方式。尚未获得的角色会显示对应状态及获取提示。

### 6.3 升级角色

1. 在角色列表中选择已拥有的角色。
2. 点击升级按钮，查看升级所需资源。
3. 资源充足时确认升级。
4. 升级成功后，页面更新角色等级和相关属性。
5. 使用自动升级时，可先查看预计目标等级和资源消耗，再确认执行。

## 7. 装备管理

### 7.1 打开装备页面

1. 在首页点击“装备”。
2. 页面显示当前装备仓库和装备详情。
3. 可按装备状态或页面分类查看可用装备。

### 7.2 查看和选择装备

点击装备条目后，可查看装备名称、品质、等级、属性、穿戴状态和升级信息。已选择的装备会在详情区域突出显示。

### 7.3 穿戴、卸下和升级

1. 选择目标装备。
2. 选择需要使用该装备的角色。
3. 点击穿戴按钮完成装备绑定；需要移除时点击卸下。
4. 点击升级或自动升级预览，查看所需资源和预期结果。
5. 确认后完成装备升级，页面同步显示最新属性。

## 8. 仓库管理

### 8.1 打开仓库

1. 在首页点击“仓库”。
2. 页面显示物品分类、已开放容量、物品槽位和详情区域。
3. 点击不同分类可筛选当前显示的物品。

### 8.2 查看物品详情

1. 点击仓库中的物品图标。
2. 查看物品图片、名称、类型、数量和用途说明。
3. 根据物品类型，页面可显示使用、出售或其他可用操作。

### 8.3 空槽位与锁定槽位

仓库中未放置物品的开放槽位显示为空。尚未开放的槽位显示锁定状态。点击可扩充的锁定槽位后，按页面提示确认所需条件和资源。

## 11. 商城与资源出售

### 11.1 浏览商城

1. 在首页点击“商城”。
2. 在商城页面切换金币商品或钻石商品分类。

## 12. 好友功能

### 12.1 查看好友和申请

1. 在首页点击“好友”。
2. 页面显示好友列表、收到的申请和发出的申请。
3. 点击对应分页查看当前内容。
4. 好友列表可显示昵称、等级、在线状态和互动状态。

### 12.2 搜索并添加好友

1. 在好友页面输入目标玩家 ID。
2. 点击搜索并核对搜索结果。
3. 点击发送申请。
4. 对方同意后，双方出现在好友列表中。

### 12.3 处理好友申请

1. 打开收到的申请列表。
2. 选择一条申请。
3. 点击同意或拒绝。
4. 打开发出的申请列表时，可查看或取消尚未处理的申请。

### 12.4 好友互动

在好友列表中选择好友后，可按页面显示执行体力赠送、每日赠礼或删除好友等操作。赠送和领取结果以页面提示及最新资源数量为准。

## 14. 模拟经营模式

### 14.1 进入经营地图

1. 在首页点击“建造”。
2. 系统加载当前账号的经营场景、地块和建筑数据。
3. 经营地图显示可使用地块、已放置地块、已建建筑和未开放区域。
4. 页面提供返回首页、仓库、任务、设置和生产收取等操作入口。

[[SCREENSHOT|图 16|模拟经营地图总览|16-management-map.png]]

### 14.2 购买或净化地块

1. 点击尚未开放的地块。
2. 在地块信息页面查看当前状态、等级条件和资源消耗。
3. 地块需要购买时，点击购买并确认。
4. 地块存在污染状态时，点击净化并确认消耗。
5. 操作成功后，地块状态更新为可放置或可建设状态。

[[SCREENSHOT|图 17|地块信息与净化操作|17-land-purification.png]]

### 14.3 放置地块和建造建筑

1. 选择已经开放且可操作的空地。
2. 点击放置或建造入口。
3. 在列表中选择目标地块或建筑。
4. 查看建筑名称、建造条件、资源消耗和所需时间。
5. 条件满足时点击确认。
6. 建造完成后，点击完成按钮使建筑进入正常状态。

### 14.4 查看建筑详情

点击已建建筑后，详情页面显示建筑名称、等级、状态、生产信息、配方和入驻角色等内容。根据建筑状态，页面可提供升级、取消、完成、移动、拆除、角色入驻和收取等按钮。

[[SCREENSHOT|图 18|建筑详情与可用操作|18-building-detail.png]]

### 14.5 升级建筑

1. 打开已建建筑详情。
2. 点击“升级”。
3. 查看升级条件、资源消耗和升级结果。
4. 确认后开始升级。
5. 升级完成时点击完成按钮，页面显示新的建筑等级。

### 14.6 移动和拆除建筑

1. 点击“移动”后，在当前经营场景中选择符合条件的目标位置。
2. 核对目标位置后确认移动。
3. 需要拆除建筑时，点击“拆除”并阅读确认提示。
4. 确认拆除后，建筑从原地块移除。

拆除操作可能影响当前建筑及其生产状态，用户应在确认目标无误后执行。

### 14.7 生产与收取

1. 打开具备生产能力的建筑。
2. 查看当前配方、生产状态、预计产出和完成时间。
3. 页面允许切换配方时，选择目标配方并确认。
4. 生产完成后点击收取，将产物加入仓库。
5. 经营地图存在多处可领取产物时，可使用一键收取功能。

[[SCREENSHOT|图 19|生产状态与收取结果|19-production-collect.png]]

### 14.8 安排和移除入驻角色

1. 打开支持角色入驻的建筑详情。
2. 点击角色入驻入口。
3. 从可用角色列表中选择目标角色。
4. 确认后，建筑详情显示当前入驻角色。
5. 需要调整时，点击移除并重新选择。

## 15. 战斗冒险模式

### 15.1 进入战斗冒险

1. 在首页点击“战斗”。
2. 系统打开战斗冒险场景。
3. 页面显示当前关卡、体力、队伍、挂机奖励和战斗入口。

### 15.2 编成队伍

1. 打开队伍编成页面。
2. 从可用角色列表中选择角色并放入队伍位置。
3. 可拖动角色调整队伍，也可使用自动填充快速编成。
4. 点击清空可移除当前编成角色。
5. 完成调整后关闭编成页面，系统保存当前队伍。

[[SCREENSHOT|图 20|战斗冒险首页与队伍编成|20-adventure-formation.png]]

### 15.3 开始关卡战斗

1. 核对当前关卡、体力和队伍状态。
2. 点击开始战斗。
3. 战斗开始后，页面显示敌我双方角色、关卡、回合和战斗状态。
4. 战斗过程中可查看技能效果、生命状态和战斗记录。
5. 点击暂停可打开暂停页面，再点击继续恢复战斗。

[[SCREENSHOT|图 21|关卡战斗界面|21-battle-screen.png]]

### 15.4 战斗结束与后续操作

关卡结束后，系统显示胜负结果和本次奖励。胜利时可按页面提示继续下一关或结束并领取；失败时可选择重试或结束。操作完成后，系统更新关卡进度和奖励状态。

### 15.5 领取挂机奖励

1. 在战斗冒险页面查看挂机奖励区域。
2. 查看累计时间和可领取数量。
3. 点击“领取奖励”。
4. 领取成功后，奖励数量重新开始累计。
5. 页面允许加速时，可在体力等条件满足后点击“加速”并确认。

## 17. 常见问题

### 17.1 无法打开软件

请检查微信客户端是否可正常使用以及设备网络是否连接。若页面提示服务器维护或版本更新，应按照提示稍后重试或完成更新。

### 17.2 无法登录

请检查账号和密码是否填写正确，并确认已勾选隐私同意选项。使用微信登录时，应完成微信授权流程。若账号处于受限或注销处理状态，应按账号管理页面提示操作。

### 17.3 页面长时间显示正在读取

请检查网络连接，等待片刻后点击页面中的刷新按钮，或返回首页重新进入该功能。网络恢复后仍无法读取时，可退出并重新登录。

### 17.4 资源数量没有及时更新

可返回首页或重新打开仓库、商城、任务等相关页面。系统同步完成后会显示最新资源数量。

### 17.5 无法购买、净化或建造

请检查地块状态、玩家等级、前置条件和所需资源。条件不足时，地块或建筑详情页面会显示原因。

### 17.6 建筑没有产出

请确认建筑已经完成建造或升级、当前配方可正常生产、原料充足且产物尚有存放空间。生产完成后需要执行收取操作。

### 17.7 无法开始战斗

请检查是否已完成队伍编成、体力是否充足、目标关卡是否开放，以及当前是否存在尚未结束的战斗。按页面提示调整后重新开始。

### 17.8 奖励未显示

请先返回首页或仓库刷新。若多次刷新后仍未显示，可记录发生时间、操作页面和系统提示，再通过游戏内客服或运营支持渠道反馈。

### 17.9 如何保护账号安全

不要向他人透露账号密码或授权信息，不要使用来源不明的游戏入口。执行退出、隐私授权、注销账号、购买或出售等操作前，应确认页面内容和目标账号无误。

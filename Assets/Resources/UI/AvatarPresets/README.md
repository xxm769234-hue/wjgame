Place the preset avatar PNG or JPG files for the profile avatar picker in this folder.

Images in this folder are loaded at runtime as Unity Sprites and displayed in the picker.

Backend preset mappings (Unity resource paths omit file extensions):

- `AVATAR_001` -> `Resources/Avatars/avatar_001`
- `AVATAR_002` -> `Resources/UI/AvatarPresets/微信图片_20260812141117_70_71`
- `AVATAR_003` -> `Resources/UI/AvatarPresets/微信图片_20260812141246_71_71`
